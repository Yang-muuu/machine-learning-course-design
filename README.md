## 离线核验

在根目录使用 Python 3.11 或更新版本运行。默认检查使用标准库，可在没有 GPU、课程数据和网络的环境中执行。

~~~bash
python -B verify_all.py
~~~

- 实验一从归档的 500 条折外预测重算混淆矩阵、准确率与 Macro-F1，并核对 200 轮监督和 25 轮伪标签日志。
- 实验二从 16,898 条配对折外概率复算前三折的单模型、融合指标，并核对 175 条训练记录。
- 实验三核对五路训练源码和逐轮日志，用两路预测重建候选 CSV。提供赛题训练坐标后可重算分支和融合 OOF。
- 实验四从 20 张留出训练图的 TP、FP、FN 重算逐图和宏平均指标，并核对分折、融合权重与训练记录。原始概率缓存和标注的重放见子目录 README。

~~~bash
python -B verify_all.py --task3-labels /path/to/fovea_localization_train_GT.csv
~~~

实验二的本地数据准备会生成分组划分。可用 `--task2-split-manifest` 复核该文件，具体参数见实验二 README。

如需同时核对手头的四份提交文件，可指定其所在目录。

~~~bash
python -B verify_all.py --kaggle-csv-dir /path/to/submission_csvs
~~~

## 重新训练

先按各任务 README 获取课程原数据和需要的公开初始化权重，并安装与本机驱动匹配的 CUDA 版 PyTorch、torchvision 和子目录依赖。归档指标复算与 GPU 重训是不同步骤。重新训练的输出可能因环境和算子精度变化。

本包发布源码、配置、训练记录和用于复查的预测或汇总。课程原图、测试标注、模型权重、账号凭据与原始对话不随包分发。各项目内列出了预训练资源来源，第三方代码沿用原许可证。
